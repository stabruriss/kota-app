# Contributing

Kota accepts issues, discussions, bug reports, documentation feedback, and
product feedback.

Kota is not accepting external code pull requests.

Please do not submit code contributions unless the project has explicitly
opened code contributions and published the applicable contribution agreement,
developer certificate process, or other inbound contribution policy.

By submitting issues, discussions, feedback, ideas, suggestions, examples, or
snippets, you grant Nan Wu, and any successor entity for Kota, permission to
use, reproduce, modify, publish, and incorporate that submission for any purpose
without obligation to accept it, attribute it, or compensate you.

This feedback policy is separate from any contribution agreement, developer
certificate process, or other inbound policy for code pull requests.

Do not submit confidential information, private credentials, proprietary
material, or content you do not have the right to share.

Report security issues through SECURITY.md.
