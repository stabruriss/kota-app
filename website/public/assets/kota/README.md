# Kota Website Assets

This directory contains web-ready Kota assets for the official website.

These files are provided for use by `kota.place` and related Kota release
pages. They are not licensed under Apache-2.0 unless a file-specific notice says
otherwise.

See the repository root `LICENSE-ASSETS` file for the policy covering Kota
official names, marks, visual identity, logos, avatars, generated media, and
other official assets.

## Contents

- `app-icons/`: Kota app icon exports for website use.
- `avatars/`: optimized system and agent avatar images.
- `icons/`: Kota UI icon SVGs used by the website.
- `tavern/`: optimized tavern backgrounds, badges, rooms, and table imagery.
